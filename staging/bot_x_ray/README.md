# Bot X-Ray

It reverse engineers Polymarket trading bots from their public trades: paste any wallet or username and it shows what the bot does, whether it was skill or luck, and whether it still works.

## Two ways to install

1. **Brainstem:** install `@kody-w/bot_x_ray`, then say "install Bot X-Ray" and "start Bot X-Ray".
2. **Any coding assistant:** paste `INSTALL_PROMPT.md`.

The app itself comes from https://part-timequant.com/kit/bot-x-ray.tar.gz; this rapplication only installs, checks, starts and stops it.
